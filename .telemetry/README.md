# ONE ERP NEXT Product Tracking

This folder contains a proposed, privacy-first product tracking **specification**, not an installed analytics agent.

- `product.md`: Product model, actors, value journeys, KPIs and safety constraints.
- `events.json`: Planned event names, owners, safe attributes and prohibited fields.
- `implementation-plan.md`: Steps to validate real ERP source and implement safely.

No user analytics is collected, no third-party telemetry service is connected, and no production infrastructure was modified. The ONE ERP preview is fictional-data only.
