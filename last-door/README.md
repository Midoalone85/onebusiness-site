# آخر باب | THE LAST DOOR

Playable MVP prototype for a social dark-fantasy decision game.

## Current MVP
- 3-door core loop
- 9 branching events
- energy / daily return loop
- coins, gems, XP, levels
- personality traits based on decisions
- inventory and cosmetics
- first-season countdown
- local save
- PWA/service worker
- prototype shop without real-money payments

## Product rule
Monetization should sell identity, cosmetics, story, and social expression, not power or manipulative paywalls.

## Next
Backend accounts, global leaderboard, live seasons, friend invites, human vote events, analytics, rewarded ads, and platform-compliant IAP.
